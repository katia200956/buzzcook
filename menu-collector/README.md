# Buzzcook Menu Collector: тест на 50 ресторанах

Програма збирає 50 випадкових ресторанів Києва з OpenStreetMap, відкриває їхні сайти,
шукає меню (сторінки, PDF, онлайн-меню, QR-коди) і витягує страви та ціни.
Тільки Python, без AI і без платних сервісів. API-ключі не потрібні.

## Що робить кожен файл

| Файл | Що робить простими словами |
| --- | --- |
| `run.py` | Запускає все по черзі і пише звіт |
| `collector/config.py` | Налаштування: місто, кількість ресторанів, паузи між запитами |
| `collector/osm.py` | А. Бере список ресторанів з OpenStreetMap і вибирає 50 |
| `collector/http.py` | Ввічливо відкриває сайти: читає robots.txt, робить паузи, нічого не обходить |
| `collector/pipeline.py` | Б, В. Перевіряє сайт, шукає посилання «Меню», PDF, онлайн-меню |
| `collector/qr.py` | Г. Читає QR-коди з картинок на сайті |
| `collector/extract.py` | Д. Знаходить назви страв, ціни, а калорії та БЖВ лише якщо вони прямо написані |
| `collector/report.py` | Е. Зберігає CSV і пише звіт `test_report.md` |
| `tests/` | Автоматичні перевірки на зразках сторінок і PDF |

## Запуск на macOS

Відкрий «Термінал» і виконуй по одному рядку:

```bash
cd "/Users/scop_1/Downloads/buzz cook/menu-collector"
python3 -m venv .venv                 # окреме середовище Python лише для цього проєкту
source .venv/bin/activate             # увімкнути його (на початку рядка з'явиться (.venv))
pip install -r requirements.txt       # встановити бібліотеки
python -m unittest discover -s tests  # перевірки: в кінці має бути OK
python run.py                         # сам тест, приблизно 10–20 хвилин
```

Якщо `python3` не знайдено, macOS запропонує встановити інструменти розробника: погодься і повтори.

## Результати (папка `output/`)

- `restaurants.csv`: ресторани і статус кожного етапу
- `dishes.csv`: витягнуті страви
- `sources.csv`: усі відкриті посилання (сайти, меню, PDF, QR)
- `test_report.md`: підсумковий звіт
- `run.log`: детальний журнал запуску

CSV відкриваються в Numbers або Excel. Дані OpenStreetMap: © учасники OpenStreetMap, ліцензія ODbL.
